## Unde se notează răspunsurile la interviuri

- **Pe claude.ai** (linkul dashboard-ului din Claude): răspunsurile se salvează pentru toată echipa. Colega are nevoie de drept de editare sau de contribuitor, dat din meniul Share al paginii.
- **Pe GitHub Pages**: răspunsurile se salvează doar în browserul în care au fost scrise. Butonul „Copiază răspunsurile ca Markdown” le scoate ca text, iar textul poate fi pus în `interviuri/` în acest repo.
